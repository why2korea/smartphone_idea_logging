## 2. 반영 내역 — ⏰ 알람 기능

### 2-1. 알람 켜고 시각 정하기

| 항목 | 내용 |
|---|---|
| 위치 | 입력 화면 — **`기록 시각` 줄 바로 아래** (제목칸 위) |
| 모양 | `☐ ⏰ 알람` 체크박스 한 줄 |
| 체크를 켜면 | 바로 아래에 **날짜칸 + 시간칸**이 나타납니다 (기록 시각과 똑같이 생긴 칸) |
| 기본 시각 | 처음 켜면 **지금부터 1시간 뒤**가 자동으로 채워집니다 |
| 안내문 | 칸 아래에 `⏰ 2026-08-13 (목) 18:47 에 알려드립니다` 처럼 정한 시각을 글로 보여줍니다 |
| 지난 시각을 고르면 | `⚠️ 이미 지난 시각입니다 — 저장하면 곧바로 알람이 울립니다` 라고 **노란 글씨로 미리 알려줍니다** (막지는 않습니다) |
| 체크를 끄면 | 날짜·시간칸이 **숨겨지고 알람도 울리지 않습니다.** 적어 둔 시각은 **지우지 않고 그대로 둡니다** → 다시 켜면 그 시각이 그대로 나옵니다 |
| 임시저장 | 알람 설정도 **1초 임시저장에 함께 담깁니다.** 글을 쓰다가 앱이 꺼져도 알람 설정이 그대로 살아납니다 |
| 저장 뒤 | 저장이 끝나면 알람 체크는 **꺼진 상태로 되돌아갑니다** (다음 메모에 실수로 딸려가지 않도록) |
| 터치 영역 | 체크박스 줄 44px, 날짜·시간칸 44px |

### 2-2. 저장된 메모 고칠 때 (상세 화면)

| 항목 | 내용 |
|---|---|
| 위치 | 히스토리 → 메모를 탭 → **`기록 시각` 칸 바로 아래에 `알람` 칸이 새로 생겼습니다** |
| 동작 | 입력 화면과 똑같습니다 (체크 → 날짜·시간칸 등장) |
| 반영 시점 | 아래 **`수정 저장`** 을 눌러야 반영됩니다 (기존 제목·본문 수정과 같은 방식) |
| 이미 울린 알람 | **시각을 바꿔 저장하면 다시 울립니다.** (`울렸음` 표시가 지워집니다) |
| 알람이 없던 옛 기록 | 체크가 꺼진 상태로 보이고, 켜면 바로 쓸 수 있습니다 (**오류 없음**) |

### 2-3. 알람이 울릴 때

| 항목 | 내용 |
|---|---|
| 확인 주기 | 앱이 **15초마다** 시각이 되었는지 살펴봅니다. 화면으로 되돌아올 때도 즉시 한 번 봅니다 |
| 울리면 | 화면 한가운데 **팝업**이 뜹니다 (기존 발송 결과 팝업과 같은 모양) |
| 팝업 내용 | `⏰ 알람` · 메모 제목 · 분류 · 알람 시각 |
| 닫기 | **`확인` 버튼** (팝업 바깥 탭 / PC는 Esc·Enter 로도 닫힙니다) |
| 스누즈 | **없습니다.** 지시대로 단순 알림 + 확인 버튼만 넣었습니다 |
| 한 번만 | 한 번 울린 알람은 기록에 `울렸음` 표시가 남아 **다시 울리지 않습니다** |
| 여러 개가 겹치면 | **줄을 세워 하나씩** 보여줍니다. 팝업에 `남은 알람: 2개` 라고 알려주고, `확인` 을 누르면 다음 알람이 이어서 뜹니다 |
| 다른 팝업과 겹치면 | `발송 중…`, `직접입력`, `잠금 해제` 팝업이 떠 있으면 **알람은 기다렸다가** 그 팝업이 닫힌 뒤에 뜹니다 |
| 앱이 꺼져 있는 동안 지난 알람 | 앱을 다시 열면 **`⏰ 지난 알람`** 으로 알려줍니다 (`앱이 꺼져 있는 동안 알람 시각이 지났습니다`) |
| 메모를 지우면 | 그 메모의 알람도 **함께 사라집니다** (알람을 따로 저장하지 않고 메모 안에 같이 넣었기 때문입니다) |
| 백업 | `JSON 내보내기` 백업에 알람 설정도 **함께 담깁니다** |

### 2-4. ⚠️ 앱이 꺼져 있을 때는 울리지 않습니다 (제일 중요)

| 상황 | 알람이 울리나 |
|---|---|
| 앱 화면을 보고 있을 때 | ✅ 예 — 바로 팝업 |
| 앱을 열어둔 채 다른 앱을 보고 있을 때 | ⚠️ 폰이 앱을 재우면 안 울리고, **앱으로 돌아오는 순간** 뜹니다 |
| 앱을 완전히 껐을 때 | ❌ 아니오 — **다시 열 때** `지난 알람` 으로 알려줍니다 |

> **왜 이렇게 했는지**
> 앱이 꺼진 상태에서 알림이 울리게 하려면 ① 브라우저 **알림 권한** 을 따로 받아야 하고
> ② 시각에 맞춰 폰을 깨워 줄 **푸시 서버** 가 있어야 합니다.
> 이 앱은 서버 없이 GitHub Pages 에 파일만 올려 쓰는 구조라 푸시 서버가 없고,
> "추가 설정(권한 등)이 필요하면 반영하지 말라" 는 지시에 따라 **이번에는 넣지 않았습니다.**

## 4. 판단해서 정한 것 (그리고 그 이유)

지시하신 대로 중간에 여쭤보지 않고 아래처럼 정했습니다.

| 갈림길 | 정한 것 | 이유 |
|---|---|---|
| 체크를 끄면 시각을 **지울까 / 남길까** | **남깁니다** (`alarmOn` 만 꺼짐) | 껐다 켤 때마다 시각을 다시 적는 것이 번거롭습니다. 데이터가 조금 남아도 해가 없고, 알람 동작은 체크(`alarmOn`) 하나로만 결정되므로 헷갈릴 일이 없습니다 |
| 알람을 **어디에 저장할까** | 메모 기록 안에 `alarmOn`·`alarmAt`·`alarmFiredAt` 세 항목으로 | 확인 체크·고정(`checked`·`pinned`)과 **같은 방식**입니다. 메모를 지우면 알람도 같이 사라지고, `JSON 내보내기` 백업에도 저절로 따라옵니다 |
| **저장 뒤** 알람 체크를 유지할까 | **끕니다** | 알람은 그 메모 하나에 붙는 것입니다. 켜둔 채로 두면 다음 메모에 실수로 알람이 붙습니다 |
| 지난 시각을 고르면 **막을까** | **막지 않고 미리 알려만 줍니다** | "3시간 전 일을 지금 기록하면서 알람을 바로 받고 싶다" 같은 쓰임을 막을 이유가 없습니다. 대신 저장 전에 노란 글씨로 알려드립니다 |
| 알람 확인 주기 | **15초** | 1분이면 최대 1분 늦게 울릴 수 있고, 1초면 배터리를 계속 씁니다. 15초면 사람이 느끼기에 "제때"이고 배터리 부담도 거의 없습니다 |
| 앱이 꺼져 있는 동안 지난 알람 | **다시 열 때 `지난 알람` 으로 알려줍니다** | 그냥 없던 일로 넘기면 알람을 맞춘 의미가 없습니다. 다만 늦었다는 사실은 분명히 알려드립니다 |
| 이미 울린 알람 | **다시 울리지 않습니다** (`alarmFiredAt` 표시) | 앱을 열 때마다 옛 알람이 계속 뜨면 못 씁니다. 다시 알림을 받고 싶으면 상세에서 **시각만 바꿔 저장**하면 됩니다 |
| 히스토리 목록에 **알람 표시(배지)** 를 넣을까 | **넣지 않았습니다** | "히스토리 화면의 체크/핀 등 다른 부분은 절대 수정하지 말 것" 이라는 지시에 따랐습니다. 필요하시면 다음에 배지만 따로 넣어드리겠습니다 |
| 백그라운드 알림 | **넣지 않았습니다** | 알림 권한 + 푸시 서버가 필요합니다 (위 2-4 참고) |

## 5. 그대로 둔 것 (건드리지 않은 부분)

원본에서 **지운 줄은 2줄뿐이고, 그마저도 뒤에 쉼표(`,`)를 붙이려고 다시 쓴 것**입니다.
나머지는 전부 **새로 더한 코드**입니다.

- 첨부파일 · 손글씨 · 음성입력 — **손대지 않았습니다**
- 자동 제목 로직(본문 첫 줄 → 첨부파일 이름) — **그대로**
- 히스토리의 **확인 체크박스 · 📌 고정(최대 5개)** — **한 줄도 고치지 않았습니다**
- 이메일 전송 4개 버튼 · 분류별 활성화 규칙 · ✍️ 직접입력 — **그대로**
- `저장 및 전송` 확인 팝업 · 발송 결과 팝업 · 개인정보 잠금 — **그대로**
- 검색 · 날짜 구분줄 · 설정 화면 · JSON 내보내기/가져오기 — **그대로**
- 색·글꼴·버튼 크기 — 기존 CSS 변수(`--accent` `--sub` `--card` `--line` `--danger`)만 썼습니다
- 새로 만든 CSS는 `.alarmbox` `.alarmhint` 두 개뿐이고,
  알람 날짜·시간칸은 기존 `.whenrow` 틀을, 알람 팝업은 기존 `.modal` `.sheet.result` 틀을 **그대로 재사용**했습니다

## 9. 확인한 것 / 확인하지 못한 것

### ✅ 자동 검사로 확인한 것 (jsdom + 크롬 headless, **91건 전부 통과**)

**알람 설정 (입력 화면)**
- 처음에는 체크 꺼짐 · 날짜/시간칸 숨김 · 안내문 없음
- 체크하면 칸이 나타나고 **지금부터 1시간 뒤**가 자동으로 채워짐
- 지난 시각을 고르면 **⚠️ 경고 문구 + 노란 강조**
- 체크를 꺼도 **적어 둔 시각이 남고**, 다시 켜면 그대로 나옴
- 임시저장(초안)에 알람이 함께 담기고 앱을 다시 열면 되살아남
- 저장 뒤 알람 체크가 꺼진 상태로 되돌아감

**저장 · 데이터**
- 저장된 기록에 `alarmOn` · `alarmAt` · `alarmFiredAt` 이 정확히 들어감
- 알람을 안 켜도 저장이 정상 동작 (`alarmOn:false`)
- 기존 항목(`checked` · `pinned` · `sentTo` · `files` …)이 전부 그대로 유지됨
- 알람이 기록 안에 들어 있어 **JSON 백업에 자동 포함**

**알람 울리기**
- 시각이 지난 알람만 뜨고, 아직 안 된 알람 · 꺼둔 알람 · 이미 울린 알람은 뜨지 않음
- **알람 항목이 아예 없던 옛 기록에서도 오류 없음**
- 한 번 울리면 `alarmFiredAt` 이 남아 **다시 울리지 않음**
- 여러 개면 **이른 시각부터 하나씩**, `남은 알람: N개` 표시, 닫으면 다음 알람
- 앱이 꺼져 있는 동안 지난 알람은 **`⏰ 지난 알람`** 으로 표시
- `확인` 버튼 · 팝업 바깥 탭 · Esc 로 닫힘
- **`발송 중…` 팝업이 떠 있으면 알람이 기다렸다가**, 닫힌 뒤에 뜸

**상세(수정) 화면**
- 저장된 알람이 체크·시각까지 그대로 나옴 / 알람 없던 옛 기록은 꺼진 상태로 나옴
- `수정 저장` 으로 알람 켜기·끄기·시각 변경이 반영됨
- 알람을 꺼도 시각은 남고, **시각을 바꾸면 다시 울림**

**화면 (크롬 headless, 폰 크기 360×740)**
- 가로 넘침 **없음** (입력 화면 · 상세 화면 · 알람 팝업 모두)
- 알람 체크줄 44px · 날짜/시간칸 44px · 팝업 `확인` 버튼 54px
- 알람을 켜도 본문칸이 최소 90px 확보되고 화면이 깨지지 않음

**기존 기능 회귀 검사**
- 히스토리 확인 체크박스 · 📌 고정 표시 그대로
- 전송 버튼 4개 · 분류별 활성화 규칙(개인용→나에게만, 회사용→4개) 그대로
- 자동 제목(본문 첫 줄 / 첨부파일 이름) 그대로
- 첨부·손글씨·직접입력 팝업(칸 5개)·발송 결과 팝업·설정 화면 그대로
