## 1. 폰에서 직접 확인한 것 (원인 규명)

폰을 USB로 연결하고 크롬 원격 디버깅으로 **실제 측정**했습니다.

### 1-1. 설정은 전부 정상이었습니다

| 확인 항목 | 결과 |
|---|---|
| 설치앱(PWA) 안 알림 권한 | ✅ `granted` |
| `periodicSync` 등록 | ✅ `w2k-alarm-check` |
| 서비스워커 | ✅ `activated` (앱을 닫아도 살아 있음) |
| 새 코드 적용 | ✅ |

> **함정 하나:** 크롬 **탭**에서 열면 권한이 `prompt`(미허용)로 나오고,
> **설치앱**에서 열면 `granted` 입니다. **둘은 별개**입니다.
> 그래서 테스트는 반드시 **홈 화면 아이콘(설치앱)** 으로 해야 합니다.

### 1-2. 그런데도 앱을 닫으면 안 울렸습니다

- 10:22 알람 등록 → 앱 완전 종료 → **알림 없음** ❌
- 실제 기록에서도 10:05 알람이 `firedAt=10:07:38` (앱을 연 순간에야 뒤늦게 처리)

### 1-3. 진짜 원인

**크롬은 웹앱이 "몇 시에 깨워달라"고 스스로 예약하는 것을 허용하지 않습니다.**

| 시도해 본 방법 | 결과 |
|---|---|
| 예약 알림 (Notification Triggers) | ❌ Chrome 150 미지원 (`showTrigger` = false) |
| 서비스워커가 스스로 기다리기 | ❌ 크롬이 30초 정도면 서비스워커를 재웁니다 |
| 주기 백그라운드 동기화 | 🔺 브라우저 마음대로 (몇 시간에 한 번) |
| 안드로이드 시계앱에 넘기기 (`intent://`) | ❌ **실제 손가락 터치로도** 크롬이 차단 |

### 1-4. 결정적 증거

서비스워커에 **푸시 신호를 넣어 봤더니** — 앱이 완전히 닫힌 상태에서

```
⏰ 알람 — ⏰테스트 10:22     ← 알림이 즉시 떴습니다 ✅
```

**즉, 알람 로직은 처음부터 완벽했습니다.**
빠진 것은 오직 **"시각이 됐을 때 폰을 깨워 줄 바깥쪽 신호"** 하나였습니다.

## 2. 해결 방법 — 웹 푸시

```
 [폰: 앱]      알람 저장
                  │  구독주소 + 서명 + 알람시각 만 보냄
                  ▼
 [GAS]        1분마다 확인 → 시각이 된 알람이 있으면 푸시 발송
                  │
                  ▼
 [구글 푸시서버] ─────────────────▶ [폰: 서비스워커] 깨어남
                                          │ IndexedDB 를 읽어
                                          ▼
                                    ⏰ 알람 — 메모제목
                                    (누르면 그 메모가 열립니다)
```

### 2-1. 1차 검증 — 푸시만 따로 시험 (2026-08-14 10:40)

앱을 **완전히 종료(force-stop)** 한 뒤, GAS가 보낼 것과 **완전히 똑같은 요청**을 PC에서 발사:

```
HTTP 201 Created                      ← 푸시 접수됨
⏰ 알람 — ⏰테스트 10:40                ← 폰에 알림 발생 ✅
tag = w2k-alarm-TEST-mssa1i0b          ← 정확히 그 알람
```

**앱이 꺼져 있어도 정시에 울리는 것을 폰에서 확인했습니다.**


### 2-2. ★ 최종 검증 — GAS 경유 실제 동작 (2026-08-14 11:00) ★

GAS 코드 붙여넣기 + `알람푸시_설치()` 트리거 생성 + 웹앱 재배포를 마친 뒤,
**PC가 전혀 개입하지 않는 상태**에서 실제와 똑같이 시험했습니다.

| 시각 | 일어난 일 |
|---|---|
| 10:55:27 | 앱 **완전 종료** (force-stop — 최근앱에서 밀어낸 것과 동일) |
| 11:00:00 | 알람 시각 |
| **11:00:54** | **`⏰ 알람 — ⏰테스트 11:00` 알림 발생** ← GAS 트리거가 푸시 발송 |
| 11:01:25 | 확인 |

- **지연 54초** — GAS가 1분마다 확인하므로 예상 범위 안입니다.
- **앱이 정말 죽어 있었다는 증거:** 알림이 뜬 시점의 앱 프로세스 생존시간이 **59초**였습니다.
  10:55 에 종료된 뒤 죽어 있다가 **푸시가 앱을 깨워서** 되살아난 것입니다.

```
앱 → GAS 등록      {"ok":true,"count":2}   ✅
GAS 1분 트리거 → 푸시 발송                  ✅
푸시 → 서비스워커 깨움 → 알림 표시           ✅
```

> **결론: 앱이 완전히 꺼져 있어도 알람이 울립니다. 목표 달성.**

### 2-3. 암호화가 필요 없는 이유 (그래서 GAS로 가능합니다)

푸시에는 **내용을 싣지 않습니다.** 그냥 "깨어나"라는 빈 신호만 보냅니다.
알림 문구(제목·분류·시각)는 **폰 안의 서비스워커가 IndexedDB를 읽어 스스로** 만듭니다.

- 덕분에 GAS가 어려운 암호화(aes128gcm)를 할 필요가 전혀 없습니다.
- 덕분에 **메모 제목·본문이 GAS로 나가지 않습니다.** (개인정보 안전)

### 2-4. 서명(VAPID)은 폰이 만듭니다

푸시 서버는 "네가 보낸 게 맞냐"를 **ES256 전자서명**으로 확인합니다.
GAS는 이 서명을 만들 수 없어서(구글 앱스 스크립트에 ECDSA 기능이 없음),

- **폰이 서명을 만들어 GAS에 맡기고**, GAS는 그것을 그대로 붙여서 보냅니다.
- 서명에 쓰는 **개인열쇠는 폰 밖으로 절대 나가지 않습니다.**
- 서명은 규격상 **최대 24시간**짜리라, 앱을 열 때마다 새로 만들어 올립니다.
  추가로 **서비스워커가 주기적으로도 갱신**하도록 넣어 두었습니다.

### 3-1. `index.html` 에 추가된 것 (`[7-D]`)

| 함수 | 하는 일 |

## 4. ★ GAS 설치 (10분, 한 번만) — ✅ 2026-08-14 완료·검증됨

> ✅ **2026-08-14 설치 완료 및 동작 확인됨.** 아래 내용은 다시 설치해야 할 때를 위한 기록입니다.
> (새 폰으로 바꾸거나 GAS 프로젝트를 다시 만들 때 그대로 따라 하시면 됩니다)


이 설치를 하지 않으면 알람은 앱을 열 때만 울립니다. (설치 전 상태)

### 1단계 — GAS 코드 교체

1. 크롬에서 https://script.google.com 접속 → **why2korea_memo** 프로젝트 열기
2. 왼쪽 `Code.gs` 클릭 → 편집창의 **내용을 전부 지우기** (Ctrl+A → Delete)
3. PC의 `C:\why2korea\claude\smartphone\gas\Code.gs` 를 메모장으로 열어
   **전체 복사(Ctrl+A → Ctrl+C)** → GAS 편집창에 **붙여넣기(Ctrl+V)**
4. **저장** (Ctrl+S)

### 2단계 — 1분 트리거 만들기 (가장 중요)

1. GAS 편집창 위쪽의 **함수 선택 드롭다운**(보통 `doPost` 라고 되어 있음)을 클릭
2. 목록에서 **`알람푸시_설치`** 를 고릅니다
3. **▶ 실행** 버튼 클릭
4. 권한 승인 창이 뜨면
   → **[권한 검토]** → 본인 구글 계정 선택
   → "Google에서 확인하지 않은 앱" 경고가 나오면
     **[고급]** → 맨 아래 **[why2korea_memo(안전하지 않음)으로 이동]** → **[허용]**
5. 아래 실행 로그에 **`설치 완료 — 1분마다 알람을 확인합니다.`** 가 나오면 성공

> 이 트리거가 **1분마다 자동으로 돌면서** 알람 시각을 확인합니다.
> 구글 무료 계정의 트리거 실행 한도(하루 90분) 안에서 충분히 돌아갑니다.

### 3단계 — 웹앱 재배포 (앱이 GAS와 통신하려면 필수)

1. 오른쪽 위 **[배포]** → **[배포 관리]**
2. 기존 배포 옆의 **연필(수정)** 아이콘 클릭
3. **버전: `새 버전`** 선택 → **[배포]**
4. **URL은 그대로 유지됩니다.** 앱 설정을 다시 만질 필요 없습니다.

### 4단계 — 폰에서 확인

1. 홈 화면의 **why2korea_memo 아이콘**으로 앱을 엽니다 (크롬 탭 말고!)
2. 아무 메모나 하나 쓰고 **⏰ 알람**을 **3분 뒤**로 걸어 저장합니다
3. **최근 앱에서 밀어서 앱을 완전히 종료**합니다
4. 3분 뒤 **⏰ 알람 — (메모제목)** 알림이 뜨면 **성공**입니다

### 5단계 — 잘 안 되면 GAS에서 점검

GAS 편집창에서 함수 드롭다운 → **`알람푸시_상태보기`** → **▶ 실행** → 로그 확인

```
1분 트리거: 있음 ✅

폰 1 (a1b2c3...)
  마지막 갱신 : 2026-08-14T11:05:00.000Z
  푸시 주소   : https://fcm.googleapis.com/fcm/send/...
  대기중 알람 : 2개
     · 08-15 06:00
```

- **"1분 트리거: 없음 ❌"** → 2단계를 다시 하세요
- **"아직 등록된 폰이 없습니다"** → 3단계(재배포)를 안 했거나, 폰에서 앱을 열고 알람을 저장하지 않았습니다
- 즉시 시험하려면 **`알람푸시_지금테스트`** 를 실행하면 바로 푸시가 날아갑니다

### 6단계 — 폰 배터리 설정 (1차 작업 문서와 동일)

- 설정 → 앱 → why2korea_memo → **배터리** → **`제한 없음`**
- 설정 → 배터리 → **백그라운드 사용 제한** → `사용하지 않는 앱을 절전 상태로 전환` **끄기**
- 설정 → 알림 → **방해 금지**를 쓰신다면 예외 앱에 추가

## 5. 개인정보는 어떻게 되나

| 항목 | 어디에 있나 |
|---|---|
| 메모 제목·본문·첨부 | **폰 안에만** (localStorage) — GAS로 안 나갑니다 |
| 알림에 뜨는 문구 | **폰 안에서 생성** (IndexedDB를 읽어 서비스워커가 만듦) |
| 서명용 개인열쇠 | **폰 안에만** (IndexedDB) — 절대 안 나갑니다 |
| GAS로 보내는 것 | 구독 주소 + 서명 + **알람 시각(숫자)** + 알람 id — 이게 전부입니다 |
| GAS가 저장하는 곳 | **스크립트 속성** (스프레드시트 아님) |

> 푸시 본문이 비어 있으므로, 중간에 누가 가로채도 **메모 내용을 알 수 없습니다.**

## 6. 올릴 파일 / 올리면 안 되는 파일

### ✅ 올려야 하는 파일 (1차 문서와 동일 + 아래)

| 파일 | 왜 |
