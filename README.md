# ⚡ why2korea_memo

떠오른 생각을 **3초 안에** 기록하는 스마트폰 웹앱입니다.
홈화면 아이콘을 누르면 곧바로 입력 화면이 열리고, 커서가 본문에 놓여 있어 바로 타이핑할 수 있습니다.

- 설치 필요 없음 (웹앱을 홈화면에 추가하면 앱처럼 전체화면으로 열립니다)
- **완전 무료** — 유료 서비스를 쓰지 않습니다
- 인터넷이 없어도 기록·저장됩니다 (기록은 휴대폰 브라우저 안에 저장)
- 음성입력 🎤 · 손글씨 입력 ✏️ · 이메일 전송 · 히스토리 검색

- 아이콘을 바꾸고 싶으면 → `tools/make_icons.py` 수정 후 다시 실행
- 자동 발송을 쓰고 싶으면 → `gas/Code.gs` (7번 항목)

> 🔒 **`index.html` 에는 실제 이메일 주소가 한 개도 없습니다.**
> 공개 저장소라서 일부러 그렇게 만들었습니다. 실제 주소는 `secrets.enc.js` 안에
> 암호로 잠겨 있고, 내 암호를 아는 사람만 열 수 있습니다.

> 📤 **어떤 파일을 GitHub에 올리고 어떤 것을 빼야 하는지**는 **12번 항목**에 표로 정리해 두었습니다.
> 위 목록에서 `LOCAL_ONLY_비밀정보.md` 와 `.claude` 폴더 두 가지만 빼면 됩니다.

## 2. 앱 사용법 요약

### 입력 화면 (앱을 켜면 바로 나옵니다)

| 위치 | 기능 |
|---|---|
| 🎤 (오른쪽 위) | 음성입력 시작/정지. 녹음 중에는 빨갛게 깜빡입니다 |
| ✏️ (오른쪽 위) | 손글씨 패널 열기/닫기 |
| 개인용 / 집안용 / 회사용 | 분류 선택. 노란색이 선택된 상태이고, 마지막에 고른 분류가 다음에도 유지됩니다 |
| 제목 | 비워두면 **본문 첫 줄이 자동으로 제목**이 됩니다 |
| 본문 | 앱을 켜면 여기에 커서가 놓입니다 |
| **저장 및 전송** (큰 노란 버튼) | **확인 팝업**이 뜹니다. 보낼 대상과 실제 이메일 주소를 눈으로 확인하고 `취소 / 저장만 / 저장 및 전송` 중에 고릅니다 |
| 나에게 / 팀장들에게 / 팀장들+영업 | 대상이 이미 정해져 있으므로 **팝업 없이 곧바로** 저장+전송 (빠른 한 번 탭용) |

### 확인 팝업 (저장 및 전송)

큰 `저장 및 전송` 버튼을 누르면 실수 전송을 막기 위해 이런 팝업이 뜹니다.

```
┌──────────────────────────────────────┐
│ 이렇게 보낼까요?                       │
│ [회사용] 오후 회의 아이디어             │
│ 손글씨 1장 첨부                        │
│                                      │
│ ◉ 나에게                              │  ← 탭해서 대상 선택
│    abc@kakao.com,                     │     (실제 주소가 그대로 보입니다)
│    abc@gmail.com                      │
│ ○ 팀장들에게                           │
│    …3명…                              │
│ ○ 팀장들+영업                          │
│    …6명…                              │
│                                      │
│  [취소]   [저장만]   [저장 및 전송]     │
└──────────────────────────────────────┘
```

- **보이는 대상은 현재 분류에서 허용된 것뿐입니다.** 개인용·집안용이면 `나에게` 하나만 나오고, 아래에 그 이유가 표시됩니다
- 기본 선택은 항상 가장 안전한 **`나에게`** 입니다. 회사용일 때 다른 대상으로 보내려면 그 줄을 탭하세요
- `취소` → 저장도 전송도 하지 않습니다. **쓰던 내용은 그대로 남아 있습니다**
- `저장만` → 기록만 저장하고 메일은 보내지 않습니다
- `저장 및 전송` → 저장한 뒤 선택한 대상에게 발송
- 팝업 밖 어두운 곳을 탭하거나 PC에서 `Esc` 를 눌러도 취소됩니다
| 히스토리 · 설정 | 다른 화면으로 이동 |

### ⚠️ 이메일 버튼 활성화 규칙

| 분류 | 나에게 | 팀장들에게 | 팀장들+영업 |
|---|---|---|---|
| 개인용 | ✅ 활성 | ⬜ 흐리게(누를 수 없음) | ⬜ 흐리게 |
| 집안용 | ✅ 활성 | ⬜ 흐리게 | ⬜ 흐리게 |
| 회사용 | ✅ 활성 | ✅ 활성 | ✅ 활성 |

분류를 바꾸면 버튼 상태가 **즉시** 따라 바뀝니다. 개인 메모가 실수로 회사 사람들에게 가는 것을 막기 위한 장치입니다.

### 자동 임시저장

입력 중인 내용은 **1초마다 자동 저장**됩니다. 앱이 갑자기 닫히거나 전화가 와서 앱이 종료돼도, 다시 열면 쓰던 내용이 그대로 남아 있습니다.

### 손글씨 (✏️)

- 손가락·애플펜슬·마우스 모두 사용 가능. 애플펜슬처럼 **필압을 지원하면 누르는 세기에 따라 선 굵기**가 달라집니다
- `되돌리기` 한 획씩 취소 / `전체 지우기` / `취소` 버리고 닫기 / `완료` 첨부
- **`완료` 를 누르지 않고 바로 `저장 및 전송`이나 이메일 버튼을 눌러도** 그린 내용이 자동으로 첨부됩니다 (그림을 잃지 않습니다)
- 한 기록에 **여러 장** 첨부할 수 있습니다. 썸네일의 `×` 로 지웁니다
- 화면을 돌려도 그림이 깨지지 않습니다

### 히스토리

- 최신순 목록. 각 항목에 날짜·분류 배지·제목·본문 미리보기·전송 여부(✓)·손글씨 썸네일 표시
- 위쪽 검색창에서 제목·본문 검색, 아래 버튼으로 분류 필터
- 항목을 탭하면 상세 화면 → **수정 / 삭제 / 다시 이메일 전송**

## 3. PC에서 테스트하기 (로컬 서버)

`index.html` 을 그냥 더블클릭해서 열면 **음성인식·PWA·서비스워커가 동작하지 않습니다.**
(브라우저 보안 규칙 때문에 `https://` 또는 `localhost` 에서만 동작합니다)

그래서 아주 간단한 로컬 서버를 띄웁니다. 파이썬은 이미 설치되어 있습니다.

### 실행

1. 시작 메뉴에서 **PowerShell** 실행
2. 아래 두 줄을 차례로 입력

```powershell
cd C:\why2korea\claude\smartphone
python -m http.server 8000
```

3. `Serving HTTP on :: port 8000 ...` 이 나오면 성공입니다.
   **이 창은 닫지 말고 그대로 두세요.** (닫으면 서버가 꺼집니다)
4. 크롬에서 접속:

```
http://localhost:8000/index.html
```

### 종료

PowerShell 창에서 **Ctrl + C** 를 누르거나 창을 닫으면 됩니다.

### PC에서 확인해볼 것

- [ ] 앱을 열면 본문에 커서가 깜빡이는지
- [ ] `개인용`/`집안용` 선택 시 `팀장들에게`·`팀장들+영업` 버튼이 흐려지고 눌리지 않는지
- [ ] `회사용` 선택 시 3개 버튼이 모두 진해지는지
- [ ] 글을 쓴 뒤 `저장 및 전송` → 확인 팝업이 뜨고, `저장만` 을 누르면 토스트가 뜨며 입력창이 비워지는지
- [ ] `회사용` 에서 팝업을 열면 대상 3개가, `개인용` 에서는 `나에게` 하나만 보이는지
- [ ] `히스토리` 에 방금 저장한 글이 보이는지, 탭하면 상세가 열리는지
- [ ] ✏️ 를 눌러 마우스로 그려지는지, `되돌리기`·`완료` 가 되는지
- [ ] 🎤 를 누르면 마이크 권한을 묻고, 말한 내용이 본문에 들어오는지 (크롬에서 동작)
- [ ] 글을 쓰다가 브라우저 탭을 닫고 다시 열면 내용이 그대로 남아 있는지
- [ ] `나에게` 를 누르면 메일 프로그램이 열리고 제목·본문·수신자가 채워져 있는지

> **참고**: 마지막 항목은 윈도우에 기본 메일 앱이 지정되어 있어야 열립니다.
> 지정되어 있지 않으면 아무 일도 일어나지 않은 것처럼 보일 수 있는데, 앱 문제가 아니라 PC 설정 문제입니다.
> 휴대폰에서는 정상적으로 메일 앱이 열립니다.

## 4. GitHub Pages로 배포하기

배포하면 `https://why2korea.github.io/smartphone_idea_logging/` 주소로 어디서나 앱을 열 수 있고,
**https 라서 음성인식과 홈화면 추가(PWA)가 정상 동작합니다.** 무료입니다.

두 가지 방법 중 편한 것을 고르세요. 입문자라면 **방법 A(마우스로 업로드)** 를 권합니다.

> 🔒 **올리기 전에 반드시 11번 항목을 먼저 읽고 `secrets.enc.js` 를 만들어 두세요.**
> 저장소를 Private으로 바꿔도 소용없습니다 — GitHub Pages는 저장소가 비공개여도
> **배포된 화면은 누구나 볼 수 있게** 공개합니다. 그래서 파일 자체를 암호로 잠급니다.

> ⚠️ `LOCAL_ONLY_비밀정보.md` 파일은 **절대 올리지 마세요.** 실제 이메일 주소가 그대로 들어 있습니다.
> (git 명령으로 올리면 `.gitignore` 가 알아서 빼줍니다. 마우스로 끌어다 놓을 때는 직접 빼세요.)

### 방법 A. 웹에서 마우스로 업로드 (명령어 없음)

**1단계 — 저장소 만들기**

1. <https://github.com> 로그인 (계정: `why2korea`)
2. 오른쪽 위 `+` → **New repository**
3. 입력값
   - Repository name: `smartphone_idea_logging`
   - **Public** 선택 ← GitHub Pages 무료 사용 조건
   - 나머지는 건드리지 않고 아래 **Create repository**

**2단계 — 파일 올리기**

4. 만들어진 저장소 화면에서 **Add file** → **Upload files**
5. 윈도우 탐색기로 `C:\why2korea\claude\smartphone` 를 열고,
	   그 안의 **파일과 폴더를 전부 선택**해서 브라우저 화면으로 끌어다 놓습니다
	   → `index.html`, `secrets.enc.js`, `manifest.json`, `sw.js`, `.gitignore`, `README.md`,
	     `icons` 폴더, `gas` 폴더, `tools` 폴더

	   > ⚠️ `smartphone` **폴더 자체를** 끌어다 놓지 마세요. 폴더 안의 내용물을 넣어야 합니다.
	   > `index.html` 이 저장소 맨 위에 있어야 합니다.
	   > ⚠️ **`LOCAL_ONLY_비밀정보.md` 와 `.claude` 폴더는 반드시 빼고** 올리세요.
	   > 전체 목록은 **12번 항목**에 표로 정리해 두었습니다.
	6. 아래 초록색 **Commit changes** 클릭

	**3단계 — Pages 켜기**

	7. 저장소 위쪽 메뉴 **Settings** → 왼쪽 목록 **Pages**
	8. `Build and deployment` 항목에서
	   - Source: **Deploy from a branch**
	   - Branch: **main** / **/(root)** 선택 → **Save**

## 7. 2단계: Google Apps Script 설정

여기까지 하면 이런 것이 됩니다.

- 메일 앱을 거치지 않고 **버튼 한 번에 바로 발송**
- **손글씨 PNG가 첨부파일로** 실제 첨부됨
- 같은 기록이 **구글 드라이브**에 텍스트+이미지로 저장됨
- **구글 스프레드시트**에 한 줄씩 로그가 쌓임

모두 무료(개인 구글 계정)이며, 하루 100통까지 발송할 수 있습니다.

### 순서

**1) 스크립트 만들기**

1. 크롬에서 <https://script.google.com> 접속 (본인 구글 계정 로그인)
2. 왼쪽 위 **새 프로젝트**
3. 왼쪽 위 `제목 없는 프로젝트` 를 클릭해 이름을 `why2korea_memo` 로 변경
4. 가운데 편집창에 원래 있던 코드(`function myFunction() {}`)를 **전부 지웁니다**
5. 이 프로젝트의 `gas\Code.gs` 파일을 메모장으로 열어 **전체 복사**(Ctrl+A → Ctrl+C)
6. 편집창에 **붙여넣기**(Ctrl+V) → **저장**(Ctrl+S)

**2) 웹앱으로 배포하기**

7. 오른쪽 위 **배포** → **새 배포**
8. 왼쪽 톱니바퀴(유형 선택) → **웹 앱**
9. 설정값 ★ 이 두 개가 가장 중요합니다
   - 설명: `why2korea_memo v1` (아무 글자나 괜찮습니다)
   - **실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
10. **배포** 클릭

**3) 권한 승인 (처음 한 번만)**

11. **액세스 승인** → 본인 구글 계정 선택
12. "Google에서 확인하지 않은 앱입니다" 경고가 나오면
    - **고급** 클릭 → 맨 아래 **why2korea_memo(안전하지 않음)으로 이동** → **허용**
    - 내가 만든 내 스크립트라 안전합니다. 구글 심사를 거치지 않았다는 뜻일 뿐입니다.

**4) URL 복사**

13. 배포가 끝나면 **웹 앱 URL** 이 나옵니다. `/exec` 로 끝나는 주소입니다.

```
https://script.google.com/macros/s/AKfycb..................../exec
```

**5) 앱에 붙여넣기**

14. 휴대폰(또는 PC)에서 why2korea_memo 앱 → **설정**
15. **✉️ 전송 방식** → **◉ 직접 발송 (Google Apps Script)** 선택
16. **Google Apps Script 웹앱 URL** 칸에 13번 주소 붙여넣기
17. **연결 테스트** → "연결 성공! 직접 발송을 쓸 수 있습니다" 확인
18. **전송 설정 저장**

끝났습니다. 이제 이메일 버튼을 누르면 "발송 중…" → "○○에게 발송 완료" 가 뜹니다.

### 만들어지는 것들

```
내 드라이브 /
  └── why2korea_memo /
        ├── why2korea_memo_log          ← 스프레드시트 로그
        └── 2026-07 /                    ← 월별 폴더
              ├── 20260730_1432_[개인용]_냉장고 우유 사기.txt
              └── 20260730_1432_손글씨1.png
```

폴더와 시트는 **스크립트가 자동으로 만듭니다.** ID를 찾아서 넣을 필요가 없습니다.

### 안전장치 (폴백)

- URL을 넣지 않았거나 비워두면 → 자동으로 **1단계 mailto 방식**으로 동작합니다
- 직접 발송이 실패하면(인터넷 문제 등) → 토스트로 알리고 **메일 앱을 대신 열어줍니다**
- 즉, 2단계가 잘 안 되더라도 앱을 못 쓰게 되는 일은 없습니다

### 미리 테스트해보기 (선택)

앱을 거치지 않고 스크립트만 먼저 확인하고 싶다면,
스크립트 편집기 위쪽 함수 선택 칸에서 **`testSendToMe`** 를 고르고 **실행** 을 누르세요.
본인 지메일로 테스트 메일이 오고, 드라이브 폴더와 시트도 만들어집니다.

## 11. 🔒 개인정보 보호 — 공개 저장소인데 왜 안전한가

### 왜 이런 게 필요한가

이 앱은 **GitHub Pages**로 배포합니다. 그래야 휴대폰에서 주소만 치면 열립니다.
그런데 GitHub Pages에는 피할 수 없는 성질이 있습니다.

> **저장소를 Private(비공개)으로 바꿔도 배포된 화면은 공개됩니다.**
> 즉 내 폰에서 열리는 그 주소로 **누구나** 접속해서 `index.html` 을 통째로 내려받을 수 있습니다.
> 브라우저에서 마우스 오른쪽 → '페이지 소스 보기' 만 하면 끝입니다.

그래서 예전처럼 코드 안에 회사 팀장님들 이메일을 적어두면,
검색엔진이 긁어가고 스팸 발송자가 수집해 갑니다. **비공개 전환으로는 막을 수 없습니다.**

### 어떻게 해결했나

**파일 자체를 암호로 잠갔습니다.**

```
[내 컴퓨터]                     [GitHub — 전 세계 공개]              [내 폰]
이메일 주소       ──잠금──▶     secrets.enc.js                ──▶   암호 입력 (처음 한 번)
GAS 주소                        "kJ8fQ2mR7xP1vN…"                    ──▶ 원래 주소로 풀림
                                (누가 봐도 의미 없는 글자)              ──▶ 폰 안에만 저장
```

| 항목 | 내용 |
|---|---|
| 암호 방식 | **AES-256-GCM** — 각국 정부·은행이 쓰는 표준 암호 |
| 암호 → 열쇠 | **PBKDF2-SHA256, 31만 회 반복** — 암호를 하나씩 대입해 보는 공격을 아주 느리게 만듭니다 |
| 위조 검사 | GCM 방식이라 암호문을 한 글자라도 건드리면 **열리지 않고 실패**합니다 |
| 쓰는 도구 | 브라우저에 원래 들어 있는 표준 기능(Web Crypto). 외부 라이브러리를 쓰지 않습니다 |
| 인터넷 전송 | **없음.** 잠그는 것도 푸는 것도 전부 내 기기 안에서만 일어납니다 |

**중요한 것은 암호의 길이입니다.** 암호문은 공개되어 있으므로, 공격자는 자기 컴퓨터로
암호를 계속 대입해 볼 수 있습니다. `1234` 같은 암호는 몇 초면 뚫립니다.
**한글 문장을 통째로** 쓰세요 — 예: `우리집강아지는초코3살!` 처럼요.
길기만 하면 현재 기술로는 사실상 뚫을 수 없습니다.

### 처음 만들기 (2분, 한 번만)

1. `tools\secret_maker.html` 을 **더블클릭**해서 엽니다 (인터넷 연결 필요 없음)
2. **② 잠글 내용** 에 이메일 주소를 넣습니다
   - `LOCAL_ONLY_비밀정보.md` 에 예전 주소들이 적혀 있으니 복사해서 붙여넣으면 됩니다
   - GAS 주소도 함께 넣으면 폰에서 발송 설정까지 자동으로 맞춰집니다
3. **③ 암호 정하기** 에 나만 아는 긴 암호를 두 번 넣습니다
4. **[암호로 잠그기]** → **[secrets.enc.js 내려받기]**
5. 내려받은 파일로 폴더의 `secrets.enc.js` 를 **덮어씁니다**
6. `sw.js` 안의 `why2korea-memo-v2` 를 `v3` 으로 한 칸 올립니다
7. GitHub에 올립니다 (4번 항목)
8. 폰에서 앱을 열면 암호를 한 번 묻습니다 → 넣으면 끝. **그 뒤로는 묻지 않습니다**

### 나중에 이메일을 바꾸고 싶을 때

같은 도구 **① 이미 만든 파일 고치기** 에서 `secrets.enc.js` 와 암호를 넣으면
원래 내용이 그대로 열립니다. 고쳐서 다시 잠그고 올리면 됩니다.
(내 암호로 언제든 열어볼 수 있습니다 — 한번 잠그면 끝인 방식이 아닙니다)

폰에는 예전 값이 이미 저장돼 있으므로,
앱 **설정 → 🔐 개인정보 잠금 → [이 기기에서 지우기] → [암호로 불러오기]** 를 한 번 해주세요.

### 폰을 잃어버렸다면

폰 안에는 풀린 이메일 주소가 저장돼 있습니다(그래야 매번 안 묻습니다).
남에게 보이기 싫은 기기에서는 잠금 해제할 때 **'이 기기에 기억하기' 체크를 끄세요.**
그러면 앱을 완전히 닫는 순간 사라지고 다음에 다시 암호를 묻습니다.

### ⚠️ 예전에 올린 것이 남아 있습니다

이미 이메일이 적힌 채로 GitHub에 올렸다면, **파일을 고쳐 올려도 예전 기록(커밋 히스토리)에는 그대로 남습니다.**
가장 확실하고 쉬운 정리 방법은 이것입니다.

1. GitHub에서 그 저장소 **Settings** → 맨 아래 **Delete this repository** 로 **완전히 삭제**
2. 같은 이름으로 **새로 만들기** (4번 항목)
3. 암호화가 끝난 지금 폴더의 파일들을 새로 올리기
4. Pages 다시 켜기 → 주소는 예전과 똑같이 유지됩니다

> 저장소를 지우면 그 안의 예전 기록도 함께 사라집니다.
> 이미 흘러나간 주소는 되돌릴 수 없지만, 더 퍼지는 것은 여기서 멈춥니다.
