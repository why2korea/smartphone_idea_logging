| 표시 | 고정된 칸은 **테두리가 노란색**으로 바뀌고 `📌 고정` 배지가 붙습니다 (필터를 바꿔도 배지는 보입니다) |
| 저장 | 기록과 같은 저장소에 `pinned`, `pinnedAt` 으로 저장 → 앱을 껐다 켜도 유지 |
| 터치 영역 | 46 × 46 px |

### 찌꺼기 정리

기록을 지우면 그 기록의 확인·고정 표시도 **함께** 사라집니다.
(표시를 따로 저장하지 않고 기록 안에 같이 넣었기 때문입니다.)
그 위에 `tidyRecordFlags()` 정리 함수를 두어, 히스토리를 열 때마다 아래를 자동으로 손봅니다.

1. `checked` · `pinned` 항목이 없던 옛 기록에 기본값(꺼짐)을 채웁니다
2. 고정이 아닌데 남아 있는 `pinnedAt`(고정 시각) 을 지웁니다
3. 어떤 이유로든 고정이 6개 이상이 되면 **오래된 것부터 풀어 5개로 맞춥니다**
4. `JSON 가져오기` 로 백업을 합칠 때도 같은 정리를 거칩니다

## 4. 반영 내역 ③ ✍️ 직접입력 전송 대상

전송 버튼이 **3개 → 4개**가 되었습니다. 맨 오른쪽이 새로 생긴 `✍️ 직접입력` 입니다.
입력 화면 아래쪽과 **히스토리 상세 화면**(다시 이메일 전송) 두 곳 모두에 들어갔습니다.

| 항목 | 내용 |
|---|---|
| 위치 | `나에게` · `팀장들에게` · `팀장들+영업` **오른쪽(마지막)** |
| 활성화 | **분류와 무관하게 언제나 활성**입니다. 개인용·집안용에서도 눌립니다 |
| 기존 3개 | **규칙 그대로** — 개인용·집안용은 `나에게` 만, 회사용은 3개 모두 |
| 최대 인원 | **5명** (입력칸 자체가 5개라 그 이상은 적을 수 없습니다) |
| 주소 검사 | `a@b.c` 모양이 아니면 그 칸이 **빨갛게** 되고 보내지 않습니다 |
| 중복 | 같은 주소를 두 번 적으면 **하나로 합쳐서** 보냅니다 |
| 빈 칸 | 그냥 두면 됩니다. 다만 **한 개도 안 적으면** 보내지 않고 안내합니다 |
| 기억하기 | `이 기기에 기억하기` 를 켜 두면 다음에 팝업을 열 때 **주소가 미리 채워집니다** (이 기기 안에만 저장) |
| 지우기 | `모두 지우기` 를 누르면 칸과 기억해 둔 주소를 함께 지웁니다 |
| 전송 이력 | 히스토리에 `✓ 직접입력` 으로 남습니다 |
| 잠금 상태 | 개인정보 잠금이 걸려 있어도 **직접입력은 보낼 수 있습니다** (주소를 직접 적었으므로) |

### 화면 흐름

```
[✍️ 직접입력] 누름
        ↓
┌──────────────────────────────────┐
│ ✍️ 받는 사람 직접 입력            │
│ [개인용] 내일 회의 자료 … — 저장한 뒤 아래 주소로 보냅니다 │
│  1 [ hong@example.com          ] │
│  2 [ kim@example.com           ] │
│  3 [ (비워 두어도 됩니다)      ] │
│  4 [ (비워 두어도 됩니다)      ] │
│  5 [ (비워 두어도 됩니다)      ] │
│  최대 5명까지 보낼 수 있습니다.  │
│  [✓] 이 기기에 기억하기          │
│  [취소] [모두 지우기] [전송]     │
└──────────────────────────────────┘
        ↓
저장 → 발송 → 결과 팝업(기존과 동일)
```

> **주의**
> `저장 및 전송` 큰 버튼(확인 팝업)은 **건드리지 않았습니다.** 거기에는 예전처럼
> 분류에 맞는 그룹만 나옵니다. 직접입력은 **아래 버튼 줄에서만** 씁니다.

## 2. 오늘 반영한 내용

### 무엇이 문제였나

`저장 및 전송` 을 누르면 결과가 화면 아래에 **작은 글씨로 2.2초만 나타났다 사라졌습니다**(토스트).
손가락을 떼고 화면을 보는 사이에 이미 사라져서, **보내진 건지 아닌지 알 수 없었습니다.**

### 어떻게 바뀌었나

결과를 **화면 한가운데 팝업** 으로 띄우고, **[확인] 을 눌러야 닫히게** 했습니다.
저절로 사라지지 않으므로 결과를 놓칠 수 없습니다.

```
┌────────────────────────────────┐
│                                │
│              ✅                │  ← 큰 아이콘 (한눈에 성공/실패)
│          발송 완료             │  ← 성공은 초록 · 실패는 빨강 · 주의는 노랑
│  ‘나에게’ 에게 메일을 보냈습니다. │
│  ┌──────────────────────────┐  │
│  │ 받는 사람: aaa@bbb.com   │  │  ← 누구에게 · 무엇이 갔는지
│  │ 첨부: 첨부파일 2개        │  │
│  │ 메일에 붙은 파일: 2개     │  │
│  └──────────────────────────┘  │
│  ┌──────────────────────────┐  │
│  │           확인            │  │  ← 이걸 눌러야 닫힙니다
│  └──────────────────────────┘  │
└────────────────────────────────┘
```

### ① 보내는 동안에도 상태가 보입니다

전송을 누르면 먼저 **`📤 발송 중…`** 팝업이 뜹니다.

- 아이콘이 천천히 깜빡여서 **작동 중** 이라는 걸 알 수 있습니다
- 이때는 **[확인] 버튼이 없고, 바깥을 눌러도 Esc를 눌러도 닫히지 않습니다**
  (결과가 나오기 전에 실수로 닫고 "보내진 건가?" 하는 일을 막기 위해서입니다)
- 응답이 오면 **같은 팝업이 그대로 결과 화면으로 바뀝니다**

### ② 성공했을 때 — 실제로 몇 개가 붙었는지까지 알려줍니다

어제 겪으신 **"보냈다는데 첨부가 빠져 있던 문제"** 를 앱이 스스로 잡아냅니다.

| 상황 | 팝업 |
|---|---|
| 첨부까지 정상 | ✅ **발송 완료** — `메일에 붙은 파일: 2개` |
| 첨부를 보냈는데 서버는 0개라고 답함 | ⚠️ **보냈지만 첨부가 빠졌습니다** + `⚠️ 파일이 붙지 않았습니다 — 앱스 스크립트를 '새 버전'으로 다시 배포해 주세요.` |

> 구글 앱스 스크립트가 알려주는 **실제 첨부 개수**(`attachments`)를 앱이 보낸 개수와 비교합니다.
> 옛 GAS처럼 개수를 아예 안 알려주면 비교하지 않고 그냥 `발송 완료` 로 표시합니다.

### ③ 실패했을 때 — 왜 실패했고 지금 뭘 해야 하는지

| 상황 | 팝업 | 안내 문구 |
|---|---|---|
| 인터넷·GAS 오류 | 📮 **자동 발송 실패 — 메일앱을 열었습니다** | 실패 이유 + `⚠️ 아직 보내지지 않았습니다. 메일앱에서 [보내기]를 눌러주세요.` |
| 메일앱(mailto) 방식 | 📮 **메일앱을 열었습니다** | 위와 같음 (메일앱은 사용자가 직접 보내기를 눌러야 나갑니다) |
| 받는 사람이 없음 | ⚠️ **보내지 못했습니다** | `설정 화면에서 받는 사람 이메일을 넣어주세요` |
| 개인정보가 잠겨 있음 | 🔒 **보내지 못했습니다** | [확인]을 누르면 **잠금 해제 창이 바로 열립니다** |
| 저장 공간 부족 | ⚠️ **저장하지 못했습니다** | `쓰신 내용은 그대로 남아 있습니다` |
| 내용이 비어 있음 | 📝 **저장할 내용이 없습니다** | [확인]을 누르면 본문칸에 커서가 갑니다 |

> **실패해도 메모는 이미 저장되어 있습니다.** 팝업에도 그렇게 적어 두었습니다.
> 히스토리 → 그 기록 → `다시 이메일 전송` 으로 다시 보내면 됩니다.

### ④ 그 외

- `저장만` 도 팝업으로 알려줍니다 (`✅ 저장했습니다` + 첨부 개수)
- 상세 화면의 `다시 이메일 전송` 도 **같은 팝업** 을 씁니다
- 팝업이 떠 있는 동안에는 **본문칸에 커서가 가지 않습니다**
  → 폰에서 키보드가 올라와 [확인] 버튼을 가리는 일을 막았습니다
- PC에서는 **Enter** 로도 [확인]이 눌립니다 (버튼에 미리 초점이 가 있습니다)
- **다른 UI는 하나도 건드리지 않았습니다.** 새로 넣은 CSS는 `.sheet.result` `.reslines` `.resline`
  세 종류뿐이고, 기존 팝업 틀(`.modal` `.sheet` `.modalbtns` `.btn`)을 그대로 재사용했습니다.
  색도 기존 변수(`--ok` `--danger` `--accent` `--card` `--line` `--sub`)만 씁니다.

