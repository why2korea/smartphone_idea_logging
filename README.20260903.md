## 1. 왜 이렇게 만들었나 (검토 과정)

처음에는 "타임블록(TimeBlocks)" 이라는 유료 구독 캘린더 앱에 직접 일정을 넣어달라는
요청이었습니다. 확인해 보니 TimeBlocks는 구글/애플 캘린더·Evernote만 **직접** 동기화하고,
바깥에서 만든 ICS 주소를 그냥 구독하는 기능은 없어서(ICSx⁵ 같은 별도 앱을 하나 더 설치해야
함), 사용자가 "복잡하다"며 **구글 캘린더로 바로 연동**하는 쪽으로 방향을 바꿨습니다.
TimeBlocks는 원래 구글 캘린더와 동기화되므로, 구글 캘린더 쪽에 반영해 두면 TimeBlocks에도
평소처럼 나타납니다.

## 2. 무엇을 어떻게 반영했나

```
[앱 index.html]                         [GAS Code.gs]                [구글 캘린더]
⏰ 알람을 켜 둔 메모가 바뀔 때마다
  (저장/수정/삭제/알람 껐다 켬)
        │
        └─ 켜진 알람 전체 목록을 통째로 ──▶ syncCalendarEvents(data)
           보냄 (id·제목·분류·시각)              │
           (설정에서 연동을 켰을 때만)            ├─ why2korea_memo 캘린더가
                                                │   없으면 새로 만듭니다
                                                │   (아무와도 공유 안 함 → 나만 보임)
                                                ├─ 새 id  → 일정 새로 만들기
                                                ├─ 시각/제목 바뀐 id → 그 일정만 고치기
                                                └─ 목록에서 사라진 id → 그 일정 지우기
```

- 캘린더에 뜨는 제목: **`[memo] 메모제목`**
- 일정 길이: 알람 시각부터 **30분**짜리로 표시 (구글 캘린더는 '점' 일정이 없어서 임의로 정함)
- 설명(description) 칸에 분류(개인용/집안용/회사용)를 적어 둡니다
- **양방향이 아닙니다.** 캘린더에서 직접 고치거나 지워도 메모 쪽에는 반영되지 않습니다.
  (다음에 알람이 한 번이라도 바뀌면 앱 쪽 내용으로 다시 덮어씁니다)

### 2-1. 켜고 끄는 방법 — 기본은 **꺼짐**

설정 화면에 **📅 구글 캘린더 연동** 이라는 새 칸을 만들었습니다.

- 체크박스를 켜면: 그 순간 GAS로 현재 켜진 알람을 전부 보내 캘린더에 반영합니다.
- 체크박스를 끄면: 빈 목록을 보내 **그동안 만들어 둔 일정을 전부 지웁니다.**
- **지금 동기화** 버튼: 알람을 안 바꿔도 즉시 한 번 맞춰 보고 싶을 때 누릅니다.
- 켜 두면, 그 뒤로는 알람이 바뀔 때마다(저장·수정·삭제·알람 껐다 켬) **자동으로** 반영됩니다.
  사람이 매번 버튼을 누를 필요가 없습니다.

### 2-2. 개인정보는 어떻게 되나 (기존 알람 푸시와 다른 점)

| 항목 | 웹 푸시(기존) | 캘린더 연동(오늘 추가) |
|---|---|---|
| GAS로 가는 것 | 구독주소·서명·**알람 시각(숫자)만** | **제목 + 분류 + 알람 시각** |
| 왜 다른가 | 빈 신호만 보내면 되므로 제목이 필요 없음 | 캘린더에 **표시해야** 하므로 제목이 필요함 |
| 본문·첨부파일·수신 이메일 | 안 감 | **똑같이 안 감** |

> 제목이 GAS로 나가는 것은 이번에 새로 생긴 변화입니다. 그래서 **기본값을 꺼짐**으로 하고,
> 사용자가 설정에서 직접 켜야만 동작하도록 만들었습니다.

## 4. ★ GAS 설치 (5분, 한 번만)

이 설치를 하지 않으면 앱에서 체크박스를 켜도 캘린더에 아무 일도 일어나지 않습니다.
(구독 주소는 이미 등록되어 있으므로, **1단계~3단계만** 새로 하면 됩니다.)

### 1단계 — GAS 코드 교체

1. 크롬에서 https://script.google.com 접속 → **why2korea_memo** 프로젝트 열기
2. 왼쪽 `Code.gs` 클릭 → 편집창 내용을 전부 지우기 (Ctrl+A → Delete)
3. PC의 `C:\why2korea\claude\smartphone\gas\Code.gs` 를 메모장으로 열어
   전체 복사 → GAS 편집창에 붙여넣기 → **저장** (Ctrl+S)

### 2단계 — 캘린더 권한 승인 (가장 중요, 새로 필요해진 단계)

이번에 처음으로 **캘린더**를 다루는 코드가 들어갔기 때문에, 구글이 새 권한을 물어봅니다.

1. 함수 선택 드롭다운에서 **`캘린더연동_설치확인`** 을 고릅니다
2. **▶ 실행** 버튼 클릭
3. 권한 승인 창이 뜨면 → **[권한 검토]** → 본인 구글 계정 선택
   → "Google에서 확인하지 않은 앱" 경고가 나오면
   **[고급]** → 맨 아래 **[why2korea_memo(안전하지 않음)으로 이동]** → **[허용]**
4. 실행 로그에 `why2korea_memo 캘린더 준비 완료 ...` 가 보이면 성공
   (이 순간 구글 캘린더에 **why2korea_memo** 라는 새 캘린더가 이미 만들어집니다)

### 3단계 — 웹앱 재배포

1. 오른쪽 위 **[배포]** → **[배포 관리]** → 기존 배포 옆 연필(수정) 아이콘
2. **버전: 새 버전** → **[배포]** (URL은 그대로 유지됩니다)

### 4단계 — 폰에서 확인

1. 홈 화면 아이콘으로 앱을 엽니다
2. **설정** → **📅 구글 캘린더 연동** → 체크박스 켜기
3. 토스트에 "완료"가 뜨는지 확인
4. 구글 캘린더(웹 또는 앱)를 열어 왼쪽 캘린더 목록에 **why2korea_memo** 가 보이는지,
   그 안에 **[memo] 메모제목** 일정이 알람 시각에 만들어졌는지 확인

### 5단계 — 잘 안 되면

- 함수 드롭다운 → **`캘린더연동_상태보기`** → ▶ 실행 → 로그에서 기기별 연동 개수 확인
- 앱 설정의 **지금 동기화** 버튼을 눌러 즉시 재시도

## 5. 남은 제약과 확인하지 못한 것

| 항목 | 설명 |
|---|---|
| **한쪽 방향만 됩니다** | 메모 → 캘린더만 반영됩니다. 캘린더에서 직접 고치면 다음 동기화 때 되돌아갑니다 |
| **일정 길이 30분 고정** | 구글 캘린더 API가 '순간' 일정을 지원하지 않아 임의로 정했습니다. 필요하면 `CAL_DURATION_MS` 값을 바꾸면 됩니다 |
| **여러 폰을 함께 쓸 때** | 기기별로 따로 연동되므로 서로 다른 폰의 일정이 섞이지 않습니다 (코드상 그렇게 설계했으나, 실제로 두 대로 시험하지는 못했습니다) |
| **실제 폰에서의 최종 확인** | 오늘은 코드 작성·문법 검사까지만 했습니다. GAS 설치(4장)와 폰에서의 실제 동작은 아직 확인하지 못했습니다 |
| **캘린더 색깔·알림 등 세부 설정** | 손대지 않았습니다. 필요하면 구글 캘린더 앱에서 **why2korea_memo** 캘린더를 직접 눌러 색깔이나 알림을 원하는 대로 바꿀 수 있습니다 |
