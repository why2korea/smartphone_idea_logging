## 1. 오늘 반영한 내용 3가지

### ① 🎤 음성입력에서 같은 말이 반복해서 쌓이던 문제 (수정)

**증상** — 마이크로 말하면 본문이 이렇게 되었습니다.

```
오후에 오후에 오후에 봉구 오후에 봉구 오후에 봉구 엔진오일 오후에 봉구 엔진오일 …
```

**원인** — 예전 방식은 *"확정된 말 조각이 올 때마다 본문 뒤에 붙이기"* 였습니다.
그런데 안드로이드 크롬·삼성 인터넷은

- 이미 준 조각을 다음 결과에 **또 넣어서** 보내고 (결과 목록이 계속 쌓임)
- 인식 중인 말을 `오후에` → `오후에 봉구` → `오후에 봉구 엔진오일` 처럼
  **점점 길어지는 형태로 여러 번 확정**해서 보냅니다.

붙이기만 하니 위처럼 겹쳐서 쌓였습니다.

**고친 방법** — *붙이기* 를 버리고 **다시 그리기** 로 바꿨습니다.

| 단계 | 하는 일 |
|---|---|
| ① | 녹음을 시작한 **커서 자리를 기억** (앞부분 `voiceHead` / 뒷부분 `voiceTail`) |
| ② | 결과가 올 때마다 확정된 조각 **전체를 처음부터 다시 계산** |
| ③ | `앞부분 + 말한 내용 + 뒷부분` 으로 본문을 **통째로 다시 씀** (`paintVoiceText`) |
| ④ | 앞부분이 겹치는 조각은 **긴 쪽만 남김** (`mergeSegments`) |

추가로 이런 상황도 함께 처리했습니다.

- 브라우저가 스스로 끊겼다가 다시 시작해도(`onend` → 재시작) 그전에 말한 내용을 잃지 않습니다
- 녹음 중에 **키보드로 직접 고쳐도** 됩니다. 그 뒤부터는 고친 커서 자리에서 이어서 받아씁니다
- 저장해서 본문이 비워져도 음성입력이 옛 글을 되살리지 않습니다
- 말이 앞뒤 글자에 달라붙지 않게 한 칸씩 띄웁니다

**고친 위치** — `index.html` → `[4] 음성입력 (🎤)` 구역
(`mergeSegments`, `resetVoiceAnchor`, `paintVoiceText`, `recognition.onresult`, `recognition.onend`, `stopVoice`)

### ② 히스토리를 '입력한 순서'가 아니라 '날짜순' 으로

- 정렬 기준을 **기록 시각** 으로 명확히 했습니다. 같은 시각이면 나중에 저장한 것이 위로 옵니다
- 날짜가 바뀌는 자리마다 **구분줄** 이 들어갑니다 → `2026-08-02 (일) · 오늘`, `2026-08-01 (토) · 어제`
- 구분줄은 스크롤해도 화면 위에 붙어 있습니다
- 날짜는 구분줄이 알려주므로, 각 항목에는 **시:분만** 표시합니다
- ③번의 지난 날짜 메모도 **그 날짜 자리에** 끼어 들어갑니다

**고친 위치** — `index.html` → `renderHistory`, `buildHistoryItem`, CSS `.daysep`

### ③ 지난 날짜로 메모 남기기 (달력 선택)

입력 화면 분류 버튼 아래에 **날짜 · 시간 · `지금`** 줄이 생겼습니다.

```
┌──────────────────────────────────────┐
│ [개인용]  [집안용]  [회사용]           │
│ [ 2026-08-02 ] [ 14:32 ] [ 지금 ]     │ ← 새로 생긴 줄
│ ⏪ 2026-07-15 (수) 로 기록됩니다        │ ← 오늘이 아닐 때만 나옵니다
│ [ 제목 ]                              │
└──────────────────────────────────────┘
```

- **기본값은 항상 오늘 날짜 · 현재 시간** 입니다. 평소에는 신경 쓸 필요가 없습니다
- 날짜칸을 누르면 **휴대폰 기본 달력** 이 떠서 지난 날짜를 고를 수 있습니다
- 오늘이 아닌 날짜를 고르면 칸이 **노랗게** 바뀌고 아래에 안내문이 나옵니다
- `지금` 버튼을 누르면 오늘·현재 시각으로 되돌아갑니다
- 저장을 마치면 자동으로 다시 오늘·지금이 됩니다
- 메일 제목과 본문의 `기록 시각` 도 **고른 날짜** 로 나갑니다
- **상세 화면에서도** 기록 시각을 고칠 수 있습니다 → `수정 저장` 을 누르면 목록에서도 그 날짜 자리로 옮겨집니다

**데이터 형식 변화**

```js
createdAt: "2026-07-15T20:00:00+09:00",   // 기록 시각 — 내가 고른 날짜 (정렬 기준)
savedAt:   "2026-08-02T10:12:00+09:00",   // ★ 새로 추가 — 실제로 저장 버튼을 누른 시각
```

> 예전에 저장한 기록에는 `savedAt` 이 없지만, 없으면 `createdAt` 을 대신 쓰므로
> **기존 기록도 그대로 정상 동작합니다.** 마이그레이션 같은 건 필요 없습니다.

**고친 위치** — `index.html` → 입력화면 HTML(`#whenRow`), 상세화면 HTML(`#detWhenRow`),
`dayKey` / `fmtDayLabel` / `fmtHm` / `fillWhenInputs` / `readWhenInputs` / `recWhen`,
`setWhen` / `getWhen` / `paintWhenHint`, `saveRecord`, `restoreDraft`, `clearInput`, `buildMail`, CSS `.whenrow`

## 3. GitHub에 올리고 갱신하는 방법

두 가지 중 편한 쪽을 쓰면 됩니다. **방법 B(git 명령)를 권합니다** — `.gitignore` 가 알아서 걸러주므로 실수가 없습니다.

### 방법 A — 웹에서 마우스로 올리기 (명령어 없음)

1. https://github.com/why2korea/smartphone_idea_logging 접속
2. 오른쪽 위 **`Add file`** → **`Upload files`**
3. 탐색기에서 아래 **4개만** 골라서 끌어다 놓습니다

   ```
   index.html
   sw.js
   README.md
   README.20260802.md
   ```

4. 아래 `Commit changes` 칸에 설명을 적습니다 → 예: `음성 중복 수정 + 히스토리 날짜순 + 지난 날짜 입력`
5. 초록색 **`Commit changes`** 버튼 클릭

> 같은 이름의 파일은 **자동으로 덮어쓰기** 됩니다. 기존 파일을 먼저 지울 필요가 없습니다.

### 방법 B — PowerShell에서 git 명령 (권장)

```powershell
cd C:\why2korea\claude\smartphone

# ① 무엇이 올라갈지 먼저 눈으로 확인 (중요)
git status

# ② 올리면 안 되는 파일이 목록에 없는지 확인한 뒤 담기
git add index.html sw.js README.md README.20260802.md

# ③ 설명을 붙여 저장
git commit -m "음성 중복 입력 수정, 히스토리 날짜순 정렬, 지난 날짜 기록 기능 추가"

# ④ GitHub로 보내기
git push
```

**`git status` 에서 이런 게 보이면 멈추세요.**

```

why2korea_memo_*.json      ← 백업 파일도 마찬가지
```

이때는 `git add .` 을 쓰지 말고 위 ②처럼 **파일 이름을 하나씩 적어서** 담으세요.

> 처음 한 번만 필요한 설정 (이미 했다면 건너뛰세요)
>
> ```powershell
> git config --global user.name  "why2korea"
> git config --global user.email "youthleeofwhy2korea@gmail.com"
> ```

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 폰에서 화면이 안 바뀐다 | `sw.js` 의 `v4` 가 실제로 올라갔는지 확인 → 앱 완전 종료 후 재실행 |
| 그래도 안 바뀐다 | 홈화면 아이콘 삭제 → 크롬으로 주소 접속해 새로고침 → 다시 홈화면에 추가 |
| 히스토리가 비어 보인다 | 기록은 폰 안에만 있습니다. **다른 브라우저/기기로 열면 안 보이는 것이 정상** 입니다 |
| 예전 기록의 날짜가 이상하다 | 상세 화면 → `기록 시각` 에서 고치고 `수정 저장` |
| 음성이 여전히 반복된다 | 앱을 완전히 종료 후 재실행(옛 코드가 캐시에 남아 있을 수 있음). 그래도 그러면 알려주세요 |
| 실수로 비밀 파일을 올렸다 | 즉시 저장소에서 삭제 + **이메일 암호를 새로 만들어** `secrets.enc.js` 를 교체 (`README.md` 11번 항목) |
